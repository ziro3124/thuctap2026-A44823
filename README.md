# Thực Tập Lập trình AI 2026

## 1. Giới thiệu

Repository phục vụ chương trình thực tập năm 2026, nhánh **Lập trình AI**, với dữ liệu giao dịch bán hàng năm 2025 của chuỗi bán lẻ thời trang trẻ em.

Mục tiêu là phân tích dữ liệu, xây dựng quy trình tiền xử lý và phát triển mô hình Machine Learning/Deep Learning phục vụ bài toán được giao.

## 2. Công nghệ dự kiến

- Python
- PostgreSQL
- pandas, NumPy
- Matplotlib, Seaborn
- scikit-learn
- PyTorch hoặc TensorFlow (tùy mô hình)

## 3. Cấu trúc repository

- `sql/`: câu truy vấn SQL và các view.
- `sql/images/`: ảnh đề bài hoặc ảnh tham khảo câu truy vấn.
- `notebooks/`: notebook EDA, tiền xử lý và thử nghiệm mô hình.
- `reports/`: báo cáo và nhật ký thực tập theo tuần.
- `models/`: code huấn luyện, đánh giá và sử dụng mô hình.

## 4. Tiến độ

- [ ] Tuần 1: thiết lập môi trường, kết nối database và repository.
- [ ] Tuần 2–3: hoàn thành bài tập SQL và các view.
- [ ] Tuần 4–5: phân tích khám phá dữ liệu (EDA).
- [ ] Tuần 6–9: xây dựng và đánh giá mô hình AI.
- [ ] Tuần 10: hoàn thiện báo cáo và tổng kết.

## 5. Bảo mật

Không lưu mật khẩu, file `.env`, dữ liệu bán hàng thô hoặc thông tin truy cập database trong repository.

## 6. Nhật ký thực tập

Nhật ký từng tuần được lưu tại `sql/tuan-XX.md`.
